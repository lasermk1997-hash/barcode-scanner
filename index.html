บัญชีที่ลงทะเบียนไว้ในเครื่องนี้ - แตะชื่อแล้วใส่รหัสเดิม (กด x 2 ครั้งเพื่อลบชื่อ)
ตั้งรหัสผ่านของบัญชี admin (ทำครั้งแรกครั้งเดียว) บัญชี admin มีได้คนเดียวและจัดการระบบได้ทุกอย่าง ถ้าเคยตั้งรหัส admin ไว้บนคอมพิวเตอร์หรือมือถือเครื่องอื่นแล้ว ไม่ต้องตั้งใหม่ - ใช้ช่อง "รหัสห้องคลาวด์" ด้านล่างเชื่อมต่อก่อน แล้วใส่รหัสเดิมได้เลย
☁ มีรหัสห้องคลาวด์ของร้าน? เชื่อมต่อเพื่อดึงรหัสผ่าน admin เดิม (ไม่ต้องตั้งใหม่)
ยังไม่มีไอดี? ไปหน้าสมัครไอดีใหม่ ›

บัญชี และสต๊อก ซิงค์กันอัตโนมัติทุกเครื่องที่เปิดไฟล์นี้ (มือถือ ↔ คอมพิวเตอร์ ไม่ต้องตั้งค่า) - ลงทะเบียนครั้งเดียว เครื่องจำไว้เอง (ธีม/เสียง/ซิงค์ อยู่ในปุ่ม ⚙ ตั้งค่า)

เมื่อเชื่อมต่อแล้ว บัญชี รหัสผ่าน และสต๊อกจะถูกจัดเก็บบนคลาวด์ เครื่องไหนใช้รหัสห้องเดียวกันข้อมูลจะตรงกันหมด: สมัคร/เปลี่ยนรหัสผ่านที่เครื่องใด เครื่องอื่นเข้าได้ทันที สแกนที่เครื่องใด ตารางทุกเครื่องอัปเดตใน ~15 วิ ลบรายการแล้วหายทุกเครื่อง

วิธีเพิ่มมือถือ/เครื่องใหม่ให้ง่ายที่สุด: กด "คัดลอกลิงก์เชิญ" ส่งลิงก์ไปที่มือถือ (LINE) แล้วเปิดลิงก์นั้น ระบบจะเชื่อมต่อห้องให้เอง บัญชีที่สมัครไว้จะโผล่ที่หน้าเข้าสู่ระบบทันที ใช้รหัสผ่านเดิมได้เลย ไม่ต้องลงทะเบียนใหม่ (รหัสห้องคือกุญแจของร้าน อย่าเปิดเผยให้คนนอกทีม ต้องมีอินเทอร์เน็ต)

ซิงค์ด้วยไฟล์ / รหัสซิงค์ (สำรอง ไม่ใช้เน็ต)
หรือใช้ "รหัสซิงค์" (ข้อความ ส่งผ่าน LINE ได้)

เครื่องใดก็ได้กด "สร้างรหัสซิงค์" คัดลอกส่งเป็นข้อความไปอีกเครื่อง (LINE/อีเมล) แล้ววางในช่องข้างบนแล้วกดนำเข้า ระบบจะรวมบัญชีและสต๊อกให้เป็นชุดเดียวกันโดยยึดรายการที่แก้ล่าสุดเสมอ ใช้ชื่อ/รหัสผ่านเดิมข้ามเครื่องได้ทันที ถ้าข้อมูลเยอะจนรหัสยาวเกินไป ให้ใช้ "ส่งออกไฟล์ข้อมูล" แทน
