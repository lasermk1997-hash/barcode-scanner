Data Matrix / QR - ใช้ได้ทั้งมือถือและคอมพิวเตอร์

บัญชีที่ลงทะเบียนไว้ในเครื่องนี้ - แตะชื่อแล้วใส่รหัสเดิม (กด x 2 ครั้งเพื่อลบชื่อ)
ตั้งรหัสผ่านของบัญชี admin (ทำครั้งแรกครั้งเดียว) บัญชี admin มีได้คนเดียวและจัดการระบบได้ทุกอย่าง ถ้าเคยตั้งรหัส admin ไว้บนคอมพิวเตอร์หรือมือถือเครื่องอื่นแล้ว ไม่ต้องตั้งใหม่ - ใช้ช่อง "รหัสห้องคลาวด์" ด้านล่างเชื่อมต่อก่อน แล้วใส่รหัสเดิมได้เลย
☁ มีรหัสห้องคลาวด์ของร้าน? เชื่อมต่อเพื่อดึงรหัสผ่าน admin เดิม (ไม่ต้องตั้งใหม่)
ยังไม่มีไอดี? ไปหน้าสมัครไอดีใหม่ ›

ลงทะเบียนครั้งเดียว เครื่องจะจำชื่อและรหัสผ่านไว้ให้เอง จนกว่าจะกดออกจากระบบ (เปลี่ยนธีม/ซิงค์ข้อมูล อยู่ในปุ่ม ⚙ ตั้งค่าหลังเข้าสู่ระบบ)

สมัครไอดีใหม่

บัญชีพนักงานสแกนรับเข้า/เบิกออกได้เท่านั้น - ชื่อ admin สงวนไว้สำหรับผู้ดูแลระบบ (พิมพ์ admin ที่หน้าเข้าสู่ระบบ)

☁ ใช้บัญชีเดิมจากคอมพิวเตอร์/เครื่องอื่น ไม่ต้องสมัครใหม่ (แนะนำ)

ใส่รหัสห้องที่ได้จาก admin แล้วกดเชื่อมต่อ ระบบจะดึงบัญชี สต๊อก และประวัติทั้งหมดมาที่เครื่องนี้ กลับไปหน้าเข้าสู่ระบบแล้วใช้ชื่อ/รหัสผ่านเดิมจากเครื่องนั้นได้เลย (ไม่ต้องลงทะเบียนใหม่)

ย้ายข้อมูลจากเครื่องเดิมโดยไม่ใช้เน็ต (สำรอง) บัญชี admin/พนักงาน + สต๊อก + ประวัติ ย้ายมาทั้งหมด
‹ กลับหน้าเข้าสู่ระบบ

☁ คลาวด์ร้าน - ซิงค์อัตโนมัติทุกเครื่อง (จำบัญชี/รหัสผ่าน/สต๊อก)

เมื่อเชื่อมต่อแล้ว บัญชี รหัสผ่าน สต๊อก และประวัติจะถูกจัดเก็บบนคลาวด์ เครื่องไหนใช้รหัสห้องเดียวกันข้อมูลจะตรงกันหมด: สมัคร/เปลี่ยนรหัสผ่านที่เครื่องใด เครื่องอื่นเข้าได้ทันที สแกนที่เครื่องใด ตารางทุกเครื่องอัปเดตใน ~15 วิ ลบรายการแล้วหายทุกเครื่อง

วิธีเพิ่มมือถือ/เครื่องใหม่ให้ง่ายที่สุด: กด "คัดลอกลิงก์เชิญ" ส่งลิงก์ไปที่มือถือ (LINE) แล้วเปิดลิงก์นั้น ระบบจะเชื่อมต่อห้องให้เอง บัญชีที่สมัครไว้จะโผล่ที่หน้าเข้าสู่ระบบทันที ใช้รหัสผ่านเดิมได้เลย ไม่ต้องลงทะเบียนใหม่ (รหัสห้องคือกุญแจของร้าน อย่าเปิดเผยให้คนนอกทีม ต้องมีอินเทอร์เน็ต)

ซิงค์ด้วยไฟล์ / รหัสซิงค์ (สำรอง ไม่ใช้เน็ต)
หรือใช้ "รหัสซิงค์" (ข้อความ ส่งผ่าน LINE ได้)

เครื่องใดก็ได้กด "สร้างรหัสซิงค์" คัดลอกส่งเป็นข้อความไปอีกเครื่อง (LINE/อีเมล) แล้ววางในช่องข้างบนแล้วกดนำเข้า ระบบจะรวมบัญชี สต๊อก และประวัติให้เป็นชุดเดียวกันโดยยึดรายการที่แก้ล่าสุดเสมอ ใช้ชื่อ/รหัสผ่านเดิมข้ามเครื่องได้ทันที ถ้าข้อมูลเยอะจนรหัสยาวเกินไป ให้ใช้ "ส่งออกไฟล์ข้อมูล" แทน
